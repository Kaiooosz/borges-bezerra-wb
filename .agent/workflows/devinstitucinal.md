Agora a parte importante.

🎯 Mentalidade

Um dev pleno:

Não executa sem analisar impacto

Não quebra padrão por conveniência

Não duplica solução já existente

Não cria “atalhos técnicos”

Ele pensa:

“Isso escala?”
“Isso mantém consistência?”
“Outro dev entenderia isso facilmente?”

🧠 Organização

Código limpo

Componentização quando necessário

Pastas organizadas

Nomeação clara

Sem comentários inúteis

Sem console.log perdido

🧱 Padrão Visual

Ele respeita:

Hierarquia de títulos

Espaçamento vertical consistente

Mesma fonte

Mesmo peso tipográfico

Mesmo estilo de botão

Mesmo padrão de hover

Mesma estrutura de container

Se o site é institucional e sóbrio, ele NÃO:

Coloca gradiente aleatório

Usa sombra exagerada

Muda radius do botão

Muda padrão de cor

📱 Responsividade

Ele sempre valida:

Mobile

Tablet

Desktop

Ele evita:
